The first downloadable build of Knowtion: a local-first workspace with pages, a block
editor, full-text search, encrypted folder sync between your own devices, Notion import,
and databases with table and board views.

This is pre-alpha. It is offered so it can be tested, not relied on. Keep anything you
would be upset to lose somewhere else as well.

## Install (Windows 10 or 11, 64-bit)

1. Download **Knowtion-Setup-0.3.0.exe** below.
2. Run it. **Windows will show a blue "Windows protected your PC" box** — this build is
   not code-signed, so SmartScreen has no publisher to vouch for it. Click **More info**,
   then **Run anyway**. If you would rather not, that is a reasonable choice; a signed
   build is on the roadmap.
3. It installs for your user only. No administrator password, nothing written outside
   your profile.

On first launch you are shown a **recovery phrase**. Write it down. The workspace is
encrypted, and the phrase is the only way back into it if the machine is lost — there is
no server and no account, so nobody can reset it for you.

## Updates

The app checks GitHub for a newer release on start and shows a banner if one exists. It
never downloads or installs anything by itself: the banner links here and you decide.
Installing a new version over an old one keeps your data.

## Uninstall

Settings → Apps → Knowtion. Your workspace is left in place deliberately. To remove it
too, delete the `Knowtion` folder under `%APPDATA%` afterwards.

## Testing

`docs/TESTING.md` in the repository is a 205-item manual checklist covering everything
this build does. Bug reports against it are the most useful thing right now.

## Known limits

- Windows only for the moment.
- Unsigned, hence the SmartScreen warning above.
- Boards render every matching row rather than paging.
- A page cannot yet be turned back into a plain page once it is a database.
