A small fix release on top of 0.4.1. Opening Knowtion a second time now brings back the
window that is already open, and the update check never offers you a test build.
Pages and data are unchanged. Still pre-alpha: keep a copy of anything you would miss.

## Opening Knowtion twice

- **Opening Knowtion again brings the open window to the front.** Double-clicking the
  shortcut a second time, or starting a second copy some other way, used to start a
  second Knowtion on the same profile. The two copies both wrote the same workspace files,
  with nothing to stop them overwriting each other. Now the second launch restores the
  window that is already open, if it was minimised, and then closes itself.

## Update check

- **A test build is never offered as an update.** Before a feature release there will be
  test builds (release candidates, such as `0.5.0-rc.1`) for testing rounds. If you are on
  a normal release, the update check ignores them, even if one were ever published by
  mistake without GitHub's pre-release flag.

## Behind the scenes

- Test builds are now published as GitHub pre-releases, which the update check never
  offers.
- Every release is checked after it is published, to confirm which version the update
  check will offer.

## Pages written by this version

Nothing changes. 0.4.2 reads and writes exactly what 0.4.1 does, so going back to 0.4.1
is safe. What the 0.4.1 notes said about older versions still holds: 0.4.0 opens a page
with line breaks or underline read-only, and 0.3.1 and earlier may drop them.

## Install (Windows 10 or 11, 64-bit)

If you are on 0.4.1, the update banner tells you about this version. 0.4.0 and older
cannot, because their update check never worked, so download it from the releases page.

Download **Knowtion-Setup-0.4.2.exe** below and run it. **Windows will show a blue
"Windows protected your PC" box.** This build is not code-signed, so SmartScreen has no
publisher to vouch for it. Click **More info**, then **Run anyway**. Installing over 0.4.1
or 0.4.0 keeps your data.

## Known limits

- Windows only, and unsigned.
- No images or attachments yet. They need a change to how files are stored and synced,
  which is being designed now, so they come after the editor and navigation work.
- No sub-pages from inside a page yet: new child pages come from the sidebar's `+`.
- One device per workspace for now.
