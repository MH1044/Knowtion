Fixes for everything a Notion user hit in an hour with 0.4.0: the typing bugs that lost or
misplaced text, Markdown shortcuts while typing, Shift+Enter, and importing Notion's
Markdown & CSV export. Still pre-alpha: keep a copy of anything you would be upset to lose.

## Typing that no longer loses text

- **The space after a web address stays.** Typing `a link to https://example.com in it.`
  used to swallow the space and pull the next word into the link.
- **Backspace below a to-do list goes back to the end of the last to-do.** It used to move
  the empty line inside the to-do, and sometimes fold the next to-do in with it.
- **A to-do typed below a to-do is its own**, not folded into the one above.
- **A code block at the end of a page can be left**: with Down, with Ctrl+Enter, or with a
  third Enter on blank lines. Clicking below the last block now writes there instead of
  going nowhere.
- **A copied to-do list pastes as to-dos**, with its ticks and nesting.

## Writing the way Notion does

- **`**bold**`, `*italic*`, `` `code` `` and `~strike~`** convert as you type.
- **Shift+Enter** starts a new line in the same block.
- **Underline**, on Ctrl+U and in the selection toolbar. Strikethrough is also on
  Ctrl+Shift+S, as in Notion.
- **`> ` makes a toggle, and `" ` a quote**, as in Notion.
- **"Untitled" is a placeholder**, not text you have to delete. A new page and a new row
  start with the caret in the title, and Enter in a page title moves into the page.
- A quote reads as a quotation. The `/` menu opens below the caret whenever it fits, the
  selection toolbar stays over the page, and the block menu opens upwards near the bottom
  of the window.

## Import and export

- **Notion's Markdown & CSV export now imports its pages**, not only its databases. Every
  page used to be reported as an attachment. Database rows keep their notes. The HTML
  export works as before.
- Markdown export writes to-do lists as tight lists, nests correctly under a to-do, and
  writes an unticked checkbox as `false`.

## Databases

- Select values show their colour in the table.
- Ticking a checkbox in a table no longer flickers.
- Choosing Board for a new view picks a property to group by, so Add works straight away.

## Update check

The check that tells you a new version exists never worked in any release so far,
because of a bug in how the app passed its answer along. It works from this version on.
**0.4.0 will not tell you about 0.4.1**, which is why you may be reading this on the
releases page.

## Pages written by this version

Line breaks and underline are new kinds of content. 0.4.0 opens a page that uses them
read-only, with a note, rather than losing them. 0.3.1 and earlier cannot tell, and may
drop them, so do not open such pages in those versions.

## Install (Windows 10 or 11, 64-bit)

Download **Knowtion-Setup-0.4.1.exe** below and run it. **Windows will show a blue
"Windows protected your PC" box.** This build is not code-signed, so SmartScreen has no
publisher to vouch for it. Click **More info**, then **Run anyway**. Installing over 0.4.0
keeps your data.

## Known limits

- Windows only, and unsigned.
- No images or attachments yet. That is next, starting with a design.
- No sub-pages from inside a page yet: new child pages come from the sidebar's `+`.
- One device per workspace for now.
