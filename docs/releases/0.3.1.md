## Export — your notes, out of Knowtion

This is the one that matters. The README has promised it since the first version and the
app never had it.

Two buttons at the bottom of the sidebar:

- **Export Markdown** writes a folder that mirrors your pages — one `.md` per page, a
  folder beside any page that has children, and a `.csv` beside every database. Open it in
  Obsidian, in VS Code, in anything. Headings, lists, checkboxes, quotes, code blocks and
  links all survive.
- **Export JSON** writes one `workspace.json` holding everything the app knows, including
  the parts Markdown cannot carry: database schemas, typed property values, and the
  identifiers that tie it all together.

Nothing is locked in, and now nothing has to be taken on trust.

## Page icons

Click the **+** beside a page's title to give it an emoji. It shows in the sidebar, where
it is actually useful. Thirty-two to choose from, or paste any other.

## Turn a database back into a page

Databases were a one-way door. Now there is a way back: the rows become ordinary child
pages, and **nothing is deleted** — turning it into a database again brings every column,
every view and every value back exactly as they were.

## Install (Windows 10 or 11, 64-bit)

Download **Knowtion-Setup-0.3.1.exe** below and run it. **Windows will show a blue
"Windows protected your PC" box** — this build is not code-signed, so SmartScreen has no
publisher to vouch for it. Click **More info**, then **Run anyway**.

It installs for your user only: no administrator password, nothing written outside your
profile. Installing over 0.3.0 keeps your data.

On first launch you are shown a **recovery phrase**. Write it down. The workspace is
encrypted and the phrase is the only way back into it — there is no server and no
account, so nobody can reset it for you.

## Testing

`docs/TESTING.md` in the repository is a 230-item manual checklist covering everything
this build does, export included. Bug reports against it are the most useful thing right
now.

## Known limits

- Windows only.
- Unsigned, hence the SmartScreen warning above.
- No images or attachments yet — you cannot paste a screenshot into a page.
- No version history yet.
- Boards render every matching row rather than paging.
